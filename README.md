# Voice Changer Android App

Simple real-time voice changer for Android.

## How to get the APK (using GitHub Actions)

1. Create a new repository on GitHub
2. Upload all files from this folder
3. Go to the **Actions** tab
4. Click **Build APK** → **Run workflow**
5. Wait 2-5 minutes
6. Download the APK from the artifacts

## Features
- Real-time voice effects (Robot, Helium, Deep, Echo, Reverb)
- Pitch, Speed and Volume controls
